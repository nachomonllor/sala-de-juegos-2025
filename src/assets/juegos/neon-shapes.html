Todo se mueve junto.

Cubrí la zona rayada con todas las piezas. No importa el color: importa el encastre.

  1. Cada flecha desliza todas las piezas hasta una pared u otra pieza. No se empujan ni se atraviesan.
  2. La zona rayada es fija y no frena el movimiento. Una pieza se detiene completa cuando una de sus celdas choca.
  3. Las piezas no giran ni cambian de forma. Para ganar, toda la zona debe quedar cubierta al mismo tiempo.
  4. Si un movimiento te deja sin salida, podés deshacer. La pista busca un camino desde tu posición actual.

El mínimo indica la solución más corta desde el inicio. Las pulsaciones que no mueven ninguna pieza no cuentan.
